# LekhaPulse.io

LekhaPulse.io is a production-oriented B2B SaaS platform for
accountants and bookkeepers.

The platform uses deterministic rules, AI-assisted transaction
classification, and human review to reduce repetitive transaction
categorization work.

## Architecture

- Frontend: React 19 + TypeScript + Vite
- Backend: Django 6 + Django Ninja
- Database: PostgreSQL
- Task Queue: Celery
- Broker/Cache: Redis
- AI: DeepSeek / OpenAI
- Deployment: Docker + GitHub Actions
